# Bakery Sales Forecasting with Weather and Economic Factors — Model Notebooks (Archive)

> ⚠️ **Archive repository.** This repository preserves the model notebooks from the experiments behind the paper below. The notebooks were developed iteratively in Google Colab over several revisions; the versions archived here may not correspond exactly to the runs reported in the paper, and saved outputs have been cleared. The code is shared as-is, is **not maintained**, and is not intended as a reproducible implementation of the reported results.

Paper: **"Forecasting the Impact of Weather and Economic Factors on Bakery Sales Using Bi-LSTM and Transformer Models"**, ASYU 2025.
DOI: [10.1109/ASYU67174.2025.11208258](https://doi.org/10.1109/ASYU67174.2025.11208258)

The study forecasts daily bakery sales for six product groups using weather and economic (oil price) features, comparing Informer, Reformer, Triformer, Time Series Transformer and Bi-LSTM.

Data preprocessing is in a separate repository: [dataset-prep repo](https://github.com/tunakodal/KoreanBakeryDatasetPreprocessRepo)
